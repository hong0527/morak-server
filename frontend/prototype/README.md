# Morak Frontend Prototype

This folder contains a standalone mobile app prototype for the Morak frontend flow.

## How to open

Open `index.html` in a browser.

The prototype is static and uses only:

- `index.html`
- `styles.css`
- `app.js`

No backend server or npm install is required.

## Included flows

- Landing and onboarding
- Birthdate validation
- Media consent
- Matching condition, matching progress, and matching complete
- Replenishment join guide
- Group, proof submission, proof feed, and rejected proof guide
- Report submission
- Result report
- Profile, manner score, withdrawal request
