## A. PRD 개요 (2026-08-11 전달분)

**한 줄 정의**: SNS를 통해 챌린지 신청과 모집 과정을 거칠 필요 없이, 조건이 맞는 6명을 자동 랜덤 매칭하여 작심삼일 문제를 해결해 주는 실시간 목표 달성 케어 서비스.

**제품 목표**
- 직접 팀원을 모집하거나 SNS 챌린지를 신청하는 번거로움을 제로화하고, 원하는 목표 시간과 관심사가 유사한 6명을 원클릭으로 랜덤 매칭한다.
- 혼자서는 포기하기 쉬운 10~30대가 가벼운 소규모 그룹 내에서 상호 인증·응원을 주고받으며 끝까지 완주하도록 독려한다.

**배경**: 기존 SNS 챌린지는 신청 절차의 부담, 낯선 사람들과의 관계 형성 부담, 혼자 인증을 이어가기 어려운 외로움 등으로 시작조차 망설이거나 중도 포기하는 경우가 많다. 직접 모집·개설할 필요가 없는 소규모(6인) 랜덤 그룹과 정해진 챌린지 기간을 제공하여 참여 장벽을 극적으로 낮춘다.

**타겟 사용자**
- 주 타겟은 **만 14세 이상 30대까지**이며, 공부·자기계발·운동·독서 등 반복 목표를 가진 사용자다.
- SNS 이용에는 익숙하지만 대규모 공개 챌린지나 직접 모집에는 부담을 느끼고, 짧고 가볍게 함께할 실천 동료를 원하는 유저다.
- **사진·실시간 캠 인증을 익명 그룹에 공유하더라도 불편하거나 위험한 상황에서 스스로 관계를 끊을 수 있기를 원하는 안전 요구가 있는 유저다.**
- **만 14세 미만은 촬영물 처리와 익명 그룹 매칭이 필요한 챌린지에 참여할 수 없다.**
- SNS 로그인에서 생년월일을 받지 못한 경우 가입 과정에서 직접 생년월일을 입력해 참여 가능 연령을 확인한다.

**핵심 피칭 페르소나**: 김도윤, 27세, 스타트업 마케터 3년차, 주 3일 재택근무로 지역 제약 없이 전국 어디서나 이용. 목표 분야는 자기계발·습관형성(미라클모닝 독서·어학공부). SNS에서 챌린지 게시물에 자주 반응하지만 신청 폼과 단톡방 자기소개 부담 때문에 실제 신청까지 3번 시도했다 포기한 경험이 있다. **기존 습관 인증 앱을 설치했지만 아무도 진지하게 검수하지 않는다는 느낌 때문에 인증을 대충 올리다 3일 만에 이탈했다 — 이는 AI 인증 진위 판별 기능의 핵심 근거가 된다.** 지불 의사는 실패 위약금(스테이크) 방식에는 거부감을 보이는 반면, AI 리마인더·피드백 같은 프리미엄 구독(가설상 월 4,900원)에는 열려 있다 — 정식 지불 의사는 사용자 인터뷰로 검증이 필요한 가설 단계다.

**사용자 시나리오**
1. (진입/신청) 만 14세 이상 사용자가 목표 분야, 하루 목표 시간, 챌린지 기간을 선택하고 '매칭 시작'을 누른다.
2. (연령 확인) SNS 로그인에서 생년월일을 받지 못한 경우 가입 과정에서 생년월일을 직접 입력하며, 만 14세 미만은 참여 제한 안내를 받고 매칭 및 사진·실시간 캠 인증을 진행할 수 없다.
3. (자동 매칭) 동일한 조건을 선택한 5명의 동료와 즉시 6인 챌린지 그룹으로 매칭된다.
4. (실천 및 인증) 매일 설정한 시간에 캠을 켜거나 완료 후 인증을 올리고, 다른 멤버의 인증에 응원 스티커를 보낸다.
5. **(자율·안전 퇴장) 개인 사정으로 참여가 어려우면 사유를 선택해 즉시 퇴장하고, 불쾌한 인증을 보면 신고 후 바로 그룹 접근을 종료한다.**
6. (현황 확인) 그룹 대시보드에서 나의 달성률과 그룹 전체의 실천 흐름을 확인한다.
7. (완주 및 리포트) 챌린지 종료 후 완주 리포트를 받고 곧바로 다음 목표 챌린지에 재참여한다.

**핵심 지표**
- 매칭 완료율: 매칭 요청을 시작한 참여자 중 6인 챌린지 그룹 배정까지 완료한 참여자의 비율.
- 매칭 대기 이탈률: 매칭 요청을 시작한 참여자 중 대기 중 취소하거나 유효 기간 만료로 종료한 참여자의 비율.
- 첫 인증 완료율: 매칭이 완료된 참여자 중 챌린지 첫 인증을 완료한 참여자의 비율.
- 정식 완주율: 챌린지 종료 시점 참여자 중 개인·그룹 이중 기준을 모두 충족해 정식 완주한 참여자의 비율.
- 30일 재참여율: 챌린지 종료 리포트를 확인한 참여자 중 종료 후 30일 안에 새 매칭 요청을 시작한 참여자의 비율.
- 신고 처리 목표 준수율: 고위험 신고는 24시간, 일반 신고는 72시간 안에 처리 완료·기각·제재 확정으로 판단이 끝난 비율.

**리스크**
- 계정 탈퇴 신청 후 30일 유예 기간 동안 SNS 제공자 식별자, 검증된 생년월일 및 프로필을 보관하므로, 유예 종료 시 자동 삭제가 누락되지 않도록 삭제 처리 결과를 점검해야 한다.
- 법령상 별도 보관이 필요한 기록이 발생할 경우 보관 대상과 기간을 개인정보 처리방침 및 운영 정책에서 별도로 확정해야 한다.
- 고위험 신고가 처리 목표 시간을 넘기거나 장기화되면 안전한 그룹 경험이 훼손될 수 있으므로, 기한 초과 신고를 운영 점검 대상으로 관리하고 임시 이용 제한을 적용해야 한다.

**속성**: 카테고리 = 생산성/업무. 사용자 역할 = 참여자, 운영관리자. 기기 = Android, iOS, PC/Web.

## B. 기능명세서 원문 (2026-08-11 전달분)

### 요구사항 1. 온보딩 및 연령 확인
신규 참여자가 SNS 계정으로 가입하고 서비스 참여 가능 연령을 확인받는 영역이다. SNS 로그인에서 생년월일을 제공받지 못한 경우 직접 입력받아 만 14세 이상 여부를 검증한다. 만 14세 미만은 매칭 및 사진·캠 인증이 필요한 챌린지 참여를 차단한다. 로그인/가입 이후의 매칭·챌린지 기능은 다른 영역에서 다룬다.

**기능 1. SNS 소셜 로그인 가입** (8/8)
사용자가 SNS 계정으로 간편 가입·로그인하는 기능이다. SNS 제공자로부터 프로필·식별자·(가능한 경우) 생년월일을 전달받아 계정을 생성한다. 별도 회원가입 폼 없이 1~2회 탭으로 온보딩을 완료하는 것을 목표로 한다.
- 근거: 기존 SNS 챌린지의 신청 절차 부담을 없애기 위해 진입 장벽을 최소화해야 한다는 배경 문제에서 도출.
- 성공 기준: 가입 시작 대비 가입 완료율로 온보딩 이탈을 측정.
- 선행조건: 지원되는 SNS 계정 보유. 트리거: 앱 최초 실행 시 'SNS로 시작하기' 버튼 탭.
- 동작: SNS 인증 완료 후 프로필과 식별자를 수신해 계정을 생성하거나 기존 계정에 로그인시킨다.
- 결과: 신규 사용자 계정이 생성되고 SNS 식별자·프로필이 저장된다.
- 예외: SNS 인증 실패·취소 시 가입 화면으로 되돌아가고 오류를 안내한다.
- 표시: SNS 제공자 선택 버튼 목록과 로딩 상태.
- 권한: 비로그인 사용자만 접근 가능하며, 로그인 완료 시 참여자 권한 부여.
- **데이터: SNS 제공자 식별자, 프로필 이미지, 닉네임, (제공 시) 생년월일을 저장한다.**

**기능 2. 생년월일 직접 입력 및 연령 검증** (8/8)
SNS 로그인에서 생년월일을 받지 못한 사용자가 가입 과정에서 직접 생년월일을 입력해 참여 가능 연령(만 14세 이상)을 검증받는 기능이다.
- 근거: 연령 확인 없이는 만 14세 미만이 촬영물 기반 인증 그룹에 노출될 위험이 있다는 리스크에서 도출.
- 성공 기준: 가입자 중 연령 검증 완료 비율.
- 선행조건: SNS 로그인 응답에 생년월일이 없는 계정. 트리거: SNS 가입 직후 생년월일 미보유 확인 시 자동 노출.
- 동작: 사용자가 생년월일을 입력하면 시스템이 만 14세 이상 여부를 계산한다.
- 결과: 검증된 생년월일이 계정에 저장되고 연령 검증 상태가 '완료'로 갱신된다.
- 예외: **만 14세 미만으로 계산되면 가입은 유지하되 매칭·인증 기능 접근을 차단하고 제한 안내로 이동시킨다.**
- 규칙: 만 14세 이상만 매칭·인증 기능에 접근할 수 있다.
- 데이터: 검증된 생년월일 필드를 계정에 저장하며 이후 수정 가능 여부는 정책으로 별도 관리한다.

**기능 3. 미성년자 참여 제한 안내** (6/6)
연령 검증 결과 만 14세 미만으로 확인된 사용자에게 참여가 제한됨을 안내하는 화면이다. 매칭·사진·캠 인증 기능으로의 진입을 차단하고 대안 안내를 제공한다.
- 결과: 사용자는 매칭·인증 화면으로 진입할 수 없는 상태로 유지된다.
- 표시: 제한 사유 문구와 문의처 안내. **재시도 불가 안내.**
- 권한: 해당 계정은 매칭 조건 선택 화면 등 챌린지 관련 화면 접근이 거부된다.

### 요구사항 2. 조건 기반 6인 자동 매칭
참여자가 목표 분야, 하루 목표 시간, 챌린지 기간을 선택하면 별도의 모집 글 작성이나 신청 절차 없이 시스템이 동일 조건의 참여자를 모아 6인 챌린지 그룹을 즉시 생성한다. 매칭 대기, 매칭 성사, 매칭 실패(대기 시간 초과 등) 상태를 관리한다.

**기능 1. 매칭 조건 선택** (7/7)
- 선행조건: **연령 검증을 통과한 참여자.** 트리거: 홈 화면의 '매칭 시작' 버튼 탭.
- 동작: 목표 분야, 하루 목표 시간, 챌린지 기간을 순서대로 선택하면 매칭 요청이 대기열에 등록된다.
- 결과: 선택한 3가지 조건이 매칭 요청 레코드로 저장되고 매칭 대기 화면으로 이동한다.
- 예외: 조건을 모두 선택하지 않으면 매칭 요청을 시작할 수 없다.
- 표시: 3단계 선택 UI와 각 단계 선택값 확인 화면.
- 데이터: 목표 분야, 하루 목표 시간, 챌린지 기간, 요청 시각.

**기능 2. 자동 랜덤 매칭 엔진** (7/7)
- 성공 기준: 매칭 완료율과 매칭 대기 이탈률.
- 선행조건: 동일 조건(목표 분야·하루 목표 시간·챌린지 기간)의 대기 중 매칭 요청이 존재.
- 트리거: 동일 조건 대기열에 신규 요청이 등록될 때마다 매칭 가능 여부를 재계산한다.
- 동작: 동일 조건 대기열에서 6명이 모이면 즉시 챌린지 그룹을 생성하고 6명을 배정한다.
- **결과: 6인 챌린지 그룹이 생성되고 전원에게 매칭 완료 알림이 발송되며 그룹 채팅·인증 공간이 활성화된다.**
- 예외: 대기 인원이 6명 미만인 상태가 지속되면 매칭이 성립되지 않는다.
- 규칙: 그룹은 정확히 6명으로 구성하며 동일 매칭 조건 참여자만 같은 그룹에 배정한다.
- 데이터: 챌린지 그룹 ID, 소속 참여자 6명, 매칭 조건, 그룹 생성 시각, 챌린지 시작·종료일.

**기능 3. 매칭 대기 및 취소** (6/6)
- 동작: 대기 중 남은 인원과 예상 대기 시간을 갱신하고, 취소 요청 시 대기열에서 제거한다.
- 결과: 취소 시 매칭 요청이 종료되고 조건 선택 화면으로 복귀하며, 매칭 성공 시 자동 랜덤 매칭 엔진으로 결과가 전달된다.
- 예외: **대기 유효 기간이 만료되면 매칭 요청이 자동 종료되고 재시도를 안내한다.**
- 표시: 대기 인원 현황(예: 4/6명)과 남은 유효 시간.

### 요구사항 3. 챌린지 실천 및 인증
6인 그룹 참여자가 매일 설정한 시간에 캠 또는 사진으로 실천을 인증하고, 다른 멤버의 인증에 응원 스티커를 보내는 영역이다. 그룹 대시보드에서 본인의 달성률과 그룹 전체의 실천 현황을 확인할 수 있다.

**기능 1. 캠/사진 실천 인증** (8/8)
그룹 참여자가 설정된 인증 시간대에 실시간 캠 또는 사진으로 실천 완료를 등록하는 기능이다. 등록된 인증은 같은 그룹 멤버에게만 공개된다.
- 성공 기준: 첫 인증 완료율과 매칭 기간 중 일일 인증율.
- 선행조건: 해당 참여자는 연령 검증을 통과하고 활성 챌린지 그룹에 소속되어 있어야 한다.
- 트리거: 설정된 일일 인증 시간대에 그룹 화면의 '인증하기' 버튼.
- 동작: 사용자가 캠을 켜거나 사진을 촬영해 업로드하면 실천 기록으로 저장된다.
- 결과: 해당 일자의 본인 인증이 완료 처리되고 **그룹 피드에 노출**되며 개인 달성률이 갱신된다.
- 예외: **인증 시간이 지난 후 업로드를 시도하면 '당일 인증 마감 초과'로 거부된다. 하루 복수 인증 제출은 최초 1건만 공식 인증으로 인정한다.**
- 표시: 인증 사진/캠 캡처 화면과 업로드 완료 토스트, 그룹 피드에서의 인증 카드.
- 권한: 인증은 같은 챌린지 그룹 멤버에게만 공개되고 그룹 외부에는 노출되지 않는다.
- 데이터: 인증 ID, 작성자, 그룹 ID, 인증 미디어(사진/캠 기록), 인증 시각.

**기능 2. 응원 스티커** (6/6)
- 근거: 친목 부담은 없되 적절한 연대감을 주는 가벼운 연결이 차별점.
- 성공 기준: 인증당 평균 응원 수.
- 동작: 스티커를 선택해 해당 인증에 부착한다.
- 결과: 인증 작성자에게 **응원 알림**이 간단히 전달된다.
- 예외: **동일 인증에 중복 응원을 보내려 하면 기존 응원을 취소하는 토글로 처리된다.**
- 표시: 인증 카드 하단에 응원 아이콘과 누적 응원 수.

**기능 3. 그룹 대시보드** (8/8)
- 성공 기준: 대시보드 일평균 방문자 수.
- 동작: 본인 및 6명 각각의 일자별 인증 완료 여부와 누적 달성률을 집계한다.
- 예외: 아직 인증이 등록되지 않은 멤버는 '미인증' 상태로 표시된다.
- 표시: 달성률 그래프와 멤버별 인증 상태 아이콘 목록.
- 권한: 본인이 소속된 그룹의 데이터만 조회 가능.
- **규칙: 달성률은 (완료한 인증 일수 / 전체 챌린지 일수) 기준으로 계산한다.**

### 요구사항 4. 자율 퇴장 및 안전 신고
참여자가 개인 사정으로 그룹을 나가거나, 불쾌하거나 위험한 인증·행동을 신고하고 즉시 그룹 접근을 끊을 수 있는 안전 장치 영역이다. 운영자 판단을 기다리지 않고 참여자 스스로 관계를 종료할 수 있도록 한다.

**기능 1. 자율 퇴장** (7/7)
- 동작: 퇴장 사유를 선택하면 즉시 해당 그룹에서 본인을 제외한다.
- 결과: 그룹 멤버 수가 감소하고 본인은 해당 그룹 접근 권한을 잃는다.
- **예외: 퇴장으로 그룹 인원이 기준 미만이 되면 공식 완주 판정 기준을 별도로 적용한다.**
- 표시: 퇴장 사유 선택 판과 퇴장 확인 다이얼로그.
- 데이터: 퇴장 이력(사유, 시각).

**기능 2. 신고 및 즉시 접근 차단** (9/9)
참여자가 불쾌하거나 위험한 인증·행동을 신고하면 신고 접수와 동시에 **본인의 해당 그룹 접근이 즉시 차단되는** 기능이다. 신고된 콘텐츠는 운영 관리자 검토 대기열로 전달된다.
- 근거: 익명 그룹의 인증이 불쾌하거나 위험할 때 운영자 판단을 기다리지 않고 즉시 그룹 접근을 끊을 수 있어야 한다는 안전 요구에서 도출.
- 성공 기준: 고위험 신고 24시간, 일반 신고 72시간 처리 준수율.
- 선행조건: 대상 인증·행동이 속한 그룹에 신고자가 소속되어 있어야 한다.
- 동작: 신고 사유를 선택해 제출하면 신고가 접수되고 동시에 **신고자의 해당 그룹 접근이 차단된다.**
- 결과: 신고 건이 운영 관리자 처리 대기열에 고위험/일반으로 등록되고, 신고자에게 접수 확인이 전달된다.
- 예외: **동일 건에 대한 중복 신고는 하나의 케이스로 병합해 처리한다.**
- 권한: 신고 건 상세 내용은 운영관리자만 조회할 수 있다.
- 규칙: 신고 접수와 접근 차단은 운영자 개입 없이 시스템이 즉시 처리하며, 추후 운영관리자 검토를 통해 신고 처리(기각·제재)가 확정된다.
- 데이터: 신고 ID, 신고자, 피신고자, 대상 그룹/인증, 신고 유형, 접수 시각, 처리 상태(미처리/처리완료/기각/제재).

### 요구사항 5. 완주 리포트 및 재참여

**기능 1. 완주 판정 및 결과 리포트** (7/7)
챌린지 종료 시각에 **AI가 1차로 개인·그룹 이중 기준 충족 여부를 자동 판정**하고, 판정 결과를 바탕으로 참여자에게 개인 달성률과 그룹 전체 결과가 담긴 리포트를 제공한다.
- 성공 기준: 정식 완주율.
- 선행조건: 챌린지 종료일 도달. 트리거: 챌린지 종료 시각에 시스템이 자동으로 판정 실행.
- 동작: 'AI 완주 판정 자동화' 기능이 산출한 개인·그룹 판정 결과를 수신해 리포트 데이터로 변환한다.
- 결과: **개인 리포트(달성률, 인증 기록, 완주 여부)와 그룹 리포트(멤버별 요약)**가 생성되어 참여자에게 제공된다.
- 표시: **완주 배지, 달성률 그래프, 그룹 멤버별 기여도**를 표시하는 리포트 화면.
- 권한: 본인이 참여한 챌린지의 리포트만 조회 가능.
- 데이터: 리포트 ID, 대상 챌린지 ID, 개인 완주 여부, 그룹 완주 여부, 생성 시각.

**기능 2. 리포트 기반 재참여 유도** (4/4)
- 성공 기준: 30일 재참여율. 트리거: 리포트 하단의 '다음 챌린지 시작하기' 버튼.
- 동작: 버튼 탭 시 매칭 조건 선택 화면으로 즉시 이동한다.

### 요구사항 6. 운영 관리자 도구

**기능 1. 신고 처리 콘솔** (6/6)
운영관리자가 접수된 신고를 고위험/일반로 구분된 목록에서 확인하고 **처리완료·기각·제재** 등으로 판단을 확정하는 관리 도구.
- 결과: 신고 상태가 판단 결과로 갱신되고, **제재 판단 시 대상 사용자에게 이용 제한이 적용된다.**
- 권한: 운영관리자 역할에게만 접근 허용.

**기능 2. 신고 SLA 모니터링** (6/6)
고위험 24시간, 일반 72시간의 처리 목표 시간을 초과한 신고를 별도로 표시해 운영 점검 대상으로 관리.
- 트리거: 시스템이 주기적으로 각 신고 건의 경과 시간을 목표 시간과 비교한다.
- 동작: 목표 시간을 초과한 건을 자동으로 점검 대상으로 분류하고 **임시 이용 제한을 검토 플래그로 걸어둔다.**
- 결과: 운영관리자에게 기한 초과 알림이 전달되고 별도 목록에 노출된다.

**기능 3. 탈퇴 유예 및 자동 삭제 관리** (9/9)
회원 탈퇴 신청 접수 후 30일 유예 기간을 관리하고, 유예 종료 시 **SNS 제공자 식별자·검증된 생년월일·프로필을 자동 삭제**하고 삭제 처리 결과를 운영관리자가 확인할 수 있는 기능.
- 트리거: 탈퇴 신청 시각으로부터 30일이 경과하는 시점.
- 결과: 계정 상태가 '삭제완료'로 변경되고 삭제 처리 이력이 운영 로그에 남는다.
- 예외: **유예 기간 중 회원이 재로그인하면 탈퇴 신청을 철회하고 계정을 복구할 수 있다.**
- 규칙: 탈퇴 신청 후 30일 이내에는 재로그인으로 철회할 수 있으며, 30일 경과 시 자동으로 되돌릴 수 없다.
- 데이터: 탈퇴 신청 계정 ID, 신청 시각, 예정 삭제 시각, 삭제 완료 시각.

### 요구사항 7. AI 실시간 판단 엔진
사람 운영자 개입 없이 AI가 인증의 진위, 콘텐츠의 위험도, 완주 여부를 실시간으로 1차 판단하는 본 서비스의 핵심 엔진이다. AI는 모든 케이스를 단독으로 최종 확정하지 않고, **판단 확신도가 낮거나 고위험으로 분류된 건만 운영관리자에게 에스컬레이션한다.**

**기능 1. AI 인증 진위 판별** (9/9)
참여자가 업로드한 사진·캠 인증이 설정된 목표 활동과 실제로 일치하는지 AI가 업로드 즉시 판별한다. **동일 사진 재사용, 인터넷 도용 이미지, 목표와 무관한 피사체** 등을 탐지해 '가짜 인증'을 걸러낸다. 목표 달성 여부에 대한 주관적 판단(예: '공부를 잘했다')은 포함하지 않는다.
- 근거: 소규모 익명 그룹은 상시 운영 인력 없이 가짜 인증을 즉시 걸러낼 수 있어야 신뢰가 유지된다.
- 성공 기준: 가짜/재사용 인증으로 인한 사후 신고 건수의 감소.
- 동작: **이미지를 분석해 선택된 목표 분야와의 관련성 점수를 계산한다. 동일 이미지 해시값을 과거 인증과 대조해 재사용 여부를 확인한다.**
- 결과: 관련성 점수가 기준치 이상이면 '통과' 처리되어 그룹 피드에 공개된다. **기준치 미달이면 '보류'로 처리되어 재업로드를 안내하거나 운영관리자 검토 대기열로 이동된다.**
- 예외: AI 판단 확신도가 임계치 근처(애매한 구간)일 때만 운영관리자에게 에스컬레이션된다.
- 표시: **인증 카드에 AI 판단 상태 배지(통과/확인중/보류).** 거부된 경우 사유와 재업로드 안내를 토스트로.
- 권한: 판단 근거(확신도·탐지 사유)는 운영관리자만 조회할 수 있다.
- 규칙: AI는 1차 판단자이며 최종 판단은 애매한 케이스에만 운영관리자가 수행한다.
- 데이터: 판단 ID, 대상 인증 ID, 판단 결과(통과/보류/거부), 확신도 점수, 판단 사유, 판단 시각.

**기능 2. AI 부적절 콘텐츠 사전 검열** (9/9)
그룹에 공개되는 모든 이미지·텍스트를 사용자 신고가 접수되기 전에 AI가 먼저 검사해 **선정적·폭력·개인정보 노출** 등 위험 신호를 탐지한다. 고위험으로 판단된 콘텐츠는 공개되지 않고 즉시 차단되며 운영관리자 검토 대기열로 이동된다.
- 근거: 익명 소규모 그룹에서 위험한 인증이 단 몇 명이라도 공개되는 시간을 줄여야 한다.
- 성공 기준: 사전 검열로 차단된 건수 대비 사후 신고로 이어진 비율로 차단 정확도를 측정.
- 선행조건: 사용자가 이미지 또는 텍스트를 그룹에 업로드하는 모든 지점(인증, 응원 대화)에 공통 적용된다.
- 트리거: 콘텐츠가 서버에 업로드되는 시점에 공개 처리 직전 단계로 자동 실행.
- 동작: **이미지에서 선정적 노출, 폭력적 장면, 식별가능 개인정보(얼굴·신분증·차량번호 등)를 탐지한다. 텍스트에서 응원 텍스트 외의 폭언·협박·스패미성 언어를 탐지한다.**
- 결과: 위험 신호가 없으면 콘텐츠가 즉시 그룹에 공개된다. 고위험 신호가 탐지되면 공개가 차단되고 운영관리자 검토 대기열에 등록된다.
- 예외: **AI가 차단한 콘텐츠는 별도 이의제기 절차 없이 운영관리자 검토로만 복구된다.**
- 표시: 차단된 사용자에게는 '검토 중' 상태를 표시하고 구체적 사유는 노출하지 않는다.
- 규칙: 모든 업로드 콘텐츠는 공개 전 예외 없이 AI 검열을 거친다.
- 데이터: 검열 ID, 대상 콘텐츠 ID, 탐지된 위험 유형, 차단 여부, 검열 시각.

- 근거: 사람이 수기로 확인하면 리포트 제공이 늘어지고 재참여 타이밍을 놓친다.
- 성공 기준: 챌린지 종료부터 리포트 제공까지 걸리는 시간 단축.
